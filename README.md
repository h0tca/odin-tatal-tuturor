# Odin, Tatăl Tuturor

Un site într-o singură pagină HTML despre Odin, zeul suprem al mitologiei nordice, asociat cu înțelepciunea, războiul și magia. Odin nu provine dintr-un mit antic greco-roman, ci din tradiția vikingă.

Deschide `index.html` în orice browser. Nu are nevoie de instalare.

Izvoare: Edda poetică (Völuspá, Hávamál, Grímnismál) și Edda în proză a lui Snorri Sturluson.
